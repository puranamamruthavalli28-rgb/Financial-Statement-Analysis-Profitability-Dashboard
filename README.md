 ## Project Overview
This project analyzes a company's financial performance from 2021 to 2025 using Microsoft Excel and Power BI.
The dashboard focuses on revenue, profitability, financial ratios, and business insights.
## Tools Used
- Microsoft Excel
- Power BI
- GitHub
## Key Analysis
- Revenue Analysis
- Gross Profit
- Operating Profit
- Profit Before Tax
- Net Profit
- Gross Profit Margin
- Operating Profit Margin
- Net Profit Margin
- Current Ratio
- Debt-to-Equity Ratio
- Revenue Growth
## Power BI Dashboard
The dashboard contains:
- Total Revenue KPI
- Total Net Profit KPI
- Net Profit Margin KPI
- Profitability Trend Analysis
- Financial Ratio Analysis
- Year Filter
## Key Business Insights
- Revenue increased from ₹50 lakh in 2021 to ₹82 lakh in 2025.
- Net profit increased from ₹6.8 lakh to ₹19.8 lakh.
- Net profit margin improved from approximately 13.6% to 24.1%.
- Current ratio increased from 1.47 to 2.06.
- Debt-to-equity ratio decreased from 1.40 to 0.83.
## Project Files
- `Financial_Statement_Analysis.xlsx` – Excel calculations and financial data
- `Financial_Statement_Analysis.pbix` – Power BI dashboard
- `Business_Insights_Report.docx` – Business insights and recommendations
- `Dashboard.png` – Power BI dashboard screenshot
## Objective

The objective of this project is to analyze financial performance and present the findings through an interactive Power BI dashboard.
